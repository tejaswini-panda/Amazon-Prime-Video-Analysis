# Amazon Prime Video Analysis Dashboard

## Project Overview

This project focuses on analyzing Amazon Prime Video content using Microsoft Power BI. An interactive dashboard was created to explore and visualize the content library based on movies and shows, IMDb ratings, IMDb votes, genres, runtime, release years, and content type.

## Objective

The objective of this project is to analyze Amazon Prime Video content and transform the data into meaningful visual insights using Power BI. The dashboard helps understand content distribution, ratings, popularity, genres, runtime, and release trends.

## Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization

## Dashboard Overview

The dashboard includes the following key metrics and visualizations:

- Total Titles
- Total Shows
- Total Movies
- Average IMDb Score
- Top Shows by IMDb Votes
- Release Trend Over the Years
- Runtime Distribution
- Movies and TV Shows Distribution
- Genre-wise Content Analysis
- Release Year and Content Type Filtering

## Key Metrics

- **Total Titles:** 3K
- **Total Shows:** 605
- **Total Movies:** 2.579K
- **Average IMDb Score:** 10.84

## Key Analysis

The dashboard provides insights into:

- Distribution of movies and TV shows
- IMDb ratings and votes
- Popular content based on IMDb votes
- Content release trends across different years
- Runtime distribution of available content
- Genre-wise distribution of movies and shows
- Comparison of movies and TV shows
- Content analysis using release year and content type filters
